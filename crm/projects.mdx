Projects is your jobs pipeline board. Pipeline value on Overview uses project data.

<Note>
This guide is a stub. Full walkthrough coming next.
</Note>

## What you can do here

- Add a job with **Add job**
- Move jobs across stages: New → Contacted → Qualified → Proposal Sent → Closed Won / Closed Lost
- Track pipeline value that feeds Overview
- Open Projects from the Manage section in the sidebar
- Keep job progress separate from contact records
