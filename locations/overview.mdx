## What you can do here

- Add a location with **Add Location**
- Review the table: Name, Address, Industry, Status, Connections, Last Synced
- Open location detail for Location Info, GBP, Local Service Ads, and Geo Target
- Use location tabs for Rankings, Inbox, and Contacts
- See locations count on Overview
