Citations help you track directory listings and keep **name, address, and phone (NAP)** consistent across the web. Citation work ties back to each business location in your organization.

Open **Citations** under Tools in the sidebar at `app.omnilocal.com/{org-slug}/...`.

<Frame>
  <img src="/images/product/citations.png" alt="Citations page showing directory listings with tracked, accurate, needs fixes, and pending statuses" />
</Frame>

## Citation statuses

Citations are grouped so you can see what needs attention:

| Status | Meaning |
| --- | --- |
| **Tracked** | Listing is being monitored |
| **Accurate** | NAP matches your location |
| **Needs fixes** | Listing has inconsistencies to correct |
| **Pending** | Citation work is still in progress |

## Add citations

<Steps>
  <Step title="Open Citations">
    In the sidebar under Tools, go to **Citations**.
  </Step>
  <Step title="Add a citation">
    Select **Add citation** to track a directory listing for a location.
  </Step>
  <Step title="Add defaults (optional)">
    Use **Add defaults** to seed common directory listings. This action requires a location.
  </Step>
</Steps>

<Note>
  **Add defaults** needs a location first. Create one under [Locations](/locations/overview) before seeding default citations.
</Note>

## Keep NAP consistent

Use Citations to:

- Track directory listings per location
- Spot NAP mismatches that need fixes
- Monitor pending and accurate listings over time

Accurate citations support local SEO alongside [Rankings](/rankings/overview) and [Reviews](/locations/reviews).
