<Note>
This guide is a stub. Full walkthrough coming next.
</Note>

## What you can do here

- Open **Citations** under Tools in the sidebar
- Add a citation with **Add citation**
- Use **Add defaults** (requires a location)
- Track directory listings for NAP consistency
- Tie citation work back to each business location
